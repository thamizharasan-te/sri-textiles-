# ஸ்ரீ டெக்ஸ்டைல்ஸ் — இணைய விற்பனைத் தளம்

புடவைகள் & ஆடைகளுக்கான சொந்த இணையக் கடை. மாதத் தளக் கட்டணம் இல்லை (Shopify தேவையில்லை).
Next.js + Turso/SQLite + Vercel Blob (படங்கள்) + COD (+ Razorpay விருப்பம்). Vercel-இல் ஏற்றத் தயார்.

## உள்ளவை
**வாங்குபவர்:** முகப்பு, வடிகட்டி/தேடல், பல படங்கள் + zoom, **அளவு தேர்வு கட்டாயம் + அளவு விவரங்கள்**, கூடை, checkout (COD / Razorpay), ஆர்டர் நிலைப் பக்கம், ஆர்டர் எண்+கைபேசியால் நிலை அறிதல், GST ரசீது, மாற்றுக் கொள்கை (பணம் திரும்பாது; அதே மதிப்புக்கு வேறு உடை), WhatsApp பொத்தான் (எண் அமைத்தால் மட்டும்).
**கடைக்காரர் (`/admin`):** உள்நுழைவு, பொருள்/அளவு/கையிருப்பு/படங்கள், வகைகள், ஆர்டர்கள் & நிலை மாற்றம், விற்பனைச் சுருக்கம், கடை அமைப்புகள் (GSTIN, டெலிவரி, WhatsApp…), கடவுச்சொல் மாற்றம்.

## உள்ளூரில் இயக்க
```bash
npm install
cp .env.example .env        # மதிப்புகளை நிரப்பவும்
ADMIN_USERNAME=owner ADMIN_PASSWORD='குறைந்தது-10-எழுத்து' npm run create-admin
npm run seed                # (விருப்பம்) மாதிரிப் பொருட்கள்
npm run dev                 # http://localhost:3000
```
சோதனை: தளத்தை `npm run build && npm start -- -p 3100` என இயக்கி, `BASE_URL=http://localhost:3100 ADMIN_PASSWORD=... npm test` (Chromium தேவை; `CHROMIUM_PATH` அமைக்கலாம்).

## பாதுகாப்பு
- கடவுச்சொற்கள் bcrypt (cost 12) hash; அமர்வு cookie: httpOnly, SameSite=Lax, சேவையகத்தில் hash செய்யப்பட்ட token
- உள்நுழைவு முயற்சி வரம்பு; எல்லா உள்ளீடுகளும் Zod-ஆல் சரிபார்ப்பு; SQL எல்லாம் parameterized
- விலை/கையிருப்பு/கட்டணம் சேவையகத்திலேயே கணக்கிடப்படும்; Razorpay கையொப்பம் + webhook கையொப்பம் சரிபார்ப்பு
- படப் பதிவேற்றம்: உண்மையான படமா என சரிபார்த்து WebP-ஆக மாற்றும்; உள்நுழைவு முயற்சி வரம்பு DB-இல் (serverless-இலும் வேலை செய்யும்)
- இரகசியங்கள் `.env`-இல் மட்டும் (git-இல் சேராது)

## வசதிகள் (புதியவை)
- **தமிழ் ↔ English (இயல்புநிலை: English):** தளம் முதலில் English-இல் திறக்கும்; தமிழ் வேண்டுபவர் தலைப்பிலோ அடிக்குறிப்பிலோ உள்ள "தமிழ்" பொத்தானை அழுத்தலாம் (இயல்பை மாற்ற: `src/lib/i18n.ts`-இல் `DEFAULT_LANG`). மொழி மாற்றி (தொலைபேசியில் "EN"/"தமிழ்" பொத்தான்). தேர்வு உலாவியில் நினைவில் இருக்கும் (cookie `st_lang`). கடைப் பக்கங்கள், பிழைச் செய்திகள், ரசீது, ஆர்டர் மின்னஞ்சல் (வாடிக்கையாளர் ஆர்டர் செய்த மொழியில்) அனைத்தும் மாறும்.
  - **கடைக்காரர் செய்ய வேண்டியது:** ஒவ்வொரு பொருளிலும் "English name / description" புலங்களையும், வகைகள் பக்கத்தில் English பெயரையும், கடை அமைப்புகளில் "English" பகுதியையும் நிரப்பவும். நிரப்பாவிட்டால் அந்தப் பகுதி தமிழிலேயே தெரியும் (தளம் உடையாது). துணி, நிறம், அளவு போன்ற பொதுச் சொற்களுக்கு English `src/lib/i18n-en.ts`-இல் உள்ளது.
  - புதிய தமிழ் உரை சேர்த்தால்: `t('தமிழ்')`-இல் எழுதி `src/lib/i18n-en.ts`-இல் English சேர்க்கவும்; `npm run i18n:check` விடுபட்டவற்றைக் காட்டும். சோதனை: `npm run test:lang`.
  - நிர்வாகப் பக்கம் தமிழில் மட்டும்.
- **முகப்பு:** 8 வகைகளும் (புடவை, சுடிதார், குர்தி, பாவாடை தாவணி, குழந்தைகள், ஆண்கள்…) ஒவ்வொன்றிலும் உடைகளும் — அனைத்து ஆடைகளும் முகப்பிலேயே.
- **`/search`:** தேடலும் வடிகட்டிகளும் (வகை, விலை, அளவு, நிறம், துணி, வரிசை). தொலைபேசியில் கீழிருந்து திறக்கும் பலகை. `/products` எளிய வகைப் பட்டியல்.
- **கணக்கு (Gmail சரிபார்ப்புடன்):** `/account/signup` → பெயர், மின்னஞ்சல், கைபேசி, கடவுச்சொல் → மின்னஞ்சலுக்கு 6 இலக்கக் குறியீடு → `/account/verify`-இல் உள்ளிட்டால் மட்டுமே கணக்கு உருவாகும். குறியீடு 10 நிமிடம் செல்லும்; 5 தவறான முயற்சிக்குப் பின் செல்லாது; மறுஅனுப்பு 60 விநாடிக்கு ஒருமுறை (அதிகபட்சம் 5). உள்நுழைவு: மின்னஞ்சல் அல்லது கைபேசி + கடவுச்சொல். `/account` (ஆர்டர் வரலாறு, முகவரி சேமிப்பு). Checkout-இல் விவரம் தானாக நிரம்பும்; கணக்கின்றியும் வாங்கலாம்.

### "Google மூலம் தொடர்க" (ஒரே கிளிக் உள்நுழைவு) அமைக்க
குறியீடு தேவையில்லை; Google ஏற்கனவே மின்னஞ்சலை உறுதி செய்திருக்கும். **Client ID/Secret சேர்த்தால் மட்டுமே** பொத்தான் தோன்றும்.
1. https://console.cloud.google.com → புதிய project → **APIs & Services → OAuth consent screen**: *External* → ஆப் பெயர் (ஸ்ரீ டெக்ஸ்டைல்ஸ்), உங்கள் மின்னஞ்சல் → Scopes: `openid`, `email`, `profile` → **Publish app** (Testing நிலையில் நீங்கள் சேர்த்த Test users மட்டுமே நுழைய முடியும்).
2. **Credentials → Create credentials → OAuth client ID** → *Web application*.
3. **Authorized redirect URIs**-இல் சரியாக இதைச் சேர்: `https://உங்கள்-தளம்/api/auth/google/callback` (உள்ளூர் சோதனைக்கு `http://localhost:3000/api/auth/google/callback`).
4. Vercel → Environment Variables: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, மற்றும் `SITE_URL=https://உங்கள்-தளம்` (redirect முகவரியுடன் பொருந்த வேண்டும்) → Redeploy.
- புதிய Google பயனர் → கணக்கு தானாக உருவாகும்; ஏற்கனவே அதே மின்னஞ்சலில் கணக்கு இருந்தால் அதனுடன் இணையும். கைபேசி எண்ணை `/account`-இல் சேர்க்கலாம்.
- பாதுகாப்பு: OAuth `state` + PKCE, உறுதி செய்யப்பட்ட மின்னஞ்சல் மட்டும் ஏற்பு, `next` தளத்துக்குள் மட்டும்.
- சோதனை: `scripts/e2e-google.ts` (போலி Google சேவையகத்துடன்).

### Gmail மூலம் குறியீடு அனுப்ப (SMTP அமைப்பு)
1. Google கணக்கில் **2-Step Verification** இயக்கு → Security → **App passwords** → ஒன்று உருவாக்கு (16 எழுத்து). சாதாரணக் கடவுச்சொல் வேலை செய்யாது.
2. Vercel → Settings → Environment Variables: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=465`, `SMTP_USER=உங்கள்@gmail.com`, `SMTP_PASS=<App password>`, `MAIL_FROM="Sri Textiles <உங்கள்@gmail.com>"` → Redeploy.
3. SMTP இல்லாத **டெமோ**வில் குறியீடு திரையிலேயே தெரியும் (சோதனைக்காக). **உண்மைத் தளத்தில் SMTP இல்லாவிட்டால் sign up முடக்கப்படும்.** (Gmail தினசரி வரம்பு சுமார் 500 மின்னஞ்சல்.)
- **தொலைபேசி வடிவம்:** கீழ்ப் பட்டி, நிலையான "கூடையில் சேர்" பட்டி, படத்தை நகர்த்திப் பார்க்கும் வசதி.
- **மாதிரிப் படங்கள்:** `public/demo` (வரையப்பட்டவை; `npx tsx scripts/gen-demo-images.ts`). உண்மைப் புகைப்படங்களை நிர்வாகத்தில் ஏற்றலாம்.

## ⚡ Vercel-இல் டெமோ (3 கிளிக், எந்த அமைப்பும் வேண்டாம்)
டெமோ காட்ட: https://vercel.com/new → `sri-textiles-` repo-வை *Import* → **Deploy**. அவ்வளவுதான்.
- Vercel-இல் `DATABASE_URL` இல்லாவிட்டால் தளம் தானாக **டெமோ முறையில்** ஓடும் (Node-இன் உள்ளமைந்த SQLite; வெளி native நூலகம் தேவையில்லை): மாதிரிக் கடை (12 உடைகள்) நிரப்பப்படும், படங்கள் தற்காலிக `/tmp`-இல் உருவாகும்.
- நிர்வாகம் முன் பக்கத்தில் இணைக்கப்படவில்லை; தனி முகவரி `/admin` → பயனர் `owner`, கடவுச்சொல் `demo12345` (மாற்ற: env `DEMO_ADMIN_PASSWORD`).
- தளம் திறக்கவில்லை என்றால் `/api/health` திறந்து வரும் செய்தியை அனுப்பவும் (டெமோ முறையில் பிழை விவரம் காட்டும்).
- முதல் பக்கம் திறக்க 4–6 விநாடி ஆகலாம் (மாதிரிக் கடை உருவாகும் நேரம்).
- **வரம்பு:** டெமோவில் தரவு நிலையானது அல்ல — Vercel instance மீளும்போது ஆர்டர்கள், மாற்றங்கள் அழிந்து மாதிரிக் கடை மீண்டும் உருவாகும்; பல instance-கள் இருந்தால் ஒவ்வொன்றிலும் தனித் தரவு இருக்கலாம். **உண்மைக் கடைக்கு இது போதாது** → கீழே உள்ள Turso + Blob படிகளைச் செய்யவும்.
- Vercel-இல் `main` branch-ஐ ஏற்றும். [PR #1](https://github.com/thamizharasan-te/sri-textiles-/pull/1)-ஐ முதலில் *Merge* செய்யவும் (அல்லது Vercel → Settings → Git → Production Branch = `claude/tamil-saree-shop-website-iqkq4i`).

## Vercel-இல் உண்மைக் கடையாக ஏற்றும் படிகள்
Vercel-இல் கோப்புகள் நிலைக்காது. அதனால் **தரவுத்தளம் Turso**-விலும் **படங்கள் Vercel Blob**-இலும் சேமிக்கப்படும். (உள்ளூரில் இவை இல்லாமலே கோப்பு அடிப்படையில் ஓடும்.)

**1. Turso தரவுத்தளம் (இலவசத் தொடக்கம்)**
- https://turso.tech → உள்நுழை → *Create Database* → பெயர் `sri-textiles`, இடம் **Mumbai (aws-ap-south-1)**.
- Database பக்கத்தில் **URL** (`libsql://…turso.io`) எடுத்துக்கொள். *Create Token* மூலம் **Auth Token** எடு.
- அட்டவணைகளை நீங்கள் உருவாக்க வேண்டாம்; தளம் முதல் முறை திறக்கும்போது தானாக உருவாகும்.

**2. நிரலை `main` branch-இல் சேர்**
- GitHub-இல் [PR #1](https://github.com/thamizharasan-te/sri-textiles-/pull/1)-ஐ *Merge* செய். (Vercel `main` branch-ஐத்தான் ஏற்றும்; அதுவரை 404 வரும்.)

**3. Vercel project**
- https://vercel.com/new → `sri-textiles-` repo-வைத் தேர்ந்தெடு → Framework: *Next.js* (தானாக) → *Deploy* (முதல் முறை சில பிழைகள் வரலாம்; அடுத்த படிகள் முடிந்ததும் Redeploy).
- **Storage** tab → *Create* → **Blob** → project-உடன் *Connect*. (`BLOB_READ_WRITE_TOKEN` தானாகச் சேரும்.)
- **Settings → Environment Variables**:
  | பெயர் | மதிப்பு |
  |---|---|
  | `DATABASE_URL` | Turso URL |
  | `DATABASE_AUTH_TOKEN` | Turso token |
  | `SITE_URL` | `https://உங்கள்-தளம்.vercel.app` (அல்லது சொந்த டொமைன்) |
  | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | (விருப்பம்) ஆர்டர் மின்னஞ்சலுக்கு |
  | `RAZORPAY_*` | **இப்போது நிரப்ப வேண்டாம்** → COD மட்டும் தோன்றும் |
- **Deployments → Redeploy**.

**4. நிர்வாகியை உருவாக்கு (ஒரு முறை, உங்கள் கணினியில்)**

## மாற்று: சொந்த VPS
`npm run build && npm start` (Node 20+). `DATABASE_URL` காலியாக விட்டால் `DATABASE_PATH` கோப்பும் `UPLOAD_DIR` கோப்புறையும் பயன்படும்; இரண்டையும் தினமும் காப்புப் பிரதி எடுக்கவும். HTTPS-க்கு Caddy/nginx பயன்படுத்தலாம்.

## கடைக்காரருக்கான சிறு வழிகாட்டி
உள்நுழைய: `உங்கள்-தளம்/admin`.
**புதிய உடை சேர்க்க:** பொருட்கள் → "+ புதிய பொருள்" → பெயர், விலை நிரப்பு → "அளவுகள்" பகுதியில் *புடவை — ஒரே அளவு* அல்லது *ஆடை — S முதல் XL* பொத்தானை அழுத்து → ஒவ்வொரு அளவுக்கும் எத்தனை உள்ளன என்று எழுது, அளவு விவரம் (எ.கா. "மார்பு 38 அங்குலம்") எழுது → படங்களைத் தொலைபேசியிலிருந்தே தேர்ந்தெடு (8 வரை) → சேமி.
**விற்றுத் தீர்ந்தால்:** பொருளைத் திறந்து அளவின் எண்ணை 0 ஆக்கு (அல்லது பட்டியலில் "விற்பனையில்" பொத்தானை அழுத்தி மறை). ஆர்டர் வரும்போது கையிருப்பு தானாகக் குறையும்.
**ஆர்டர்:** ஆர்டர்கள் → ஆர்டரைத் திற → நிலையைத் தேர்ந்து "மாற்று". வாங்குபவர் தன் பக்கத்தில் புதிய நிலையைப் பார்ப்பார். COD பணம் வாங்கியதும் நிலையை "கொடுக்கப்பட்டது" என்று மாற்றினால் பணம் பெறப்பட்டதாகப் பதிவாகும். "ரத்து" செய்தால் கையிருப்பு திரும்பச் சேரும்.
**ரசீது:** ஆர்டர் பக்கத்தில் "GST ரசீது / அச்சிடு".
**WhatsApp இணைக்க:** கடை அமைப்புகள் → WhatsApp எண்ணை நிரப்பு → சேமி. தளத்தில் பச்சைப் பொத்தான் தானாகத் தோன்றும்.
**கடவுச்சொல் மறந்தால்:** மேலே படி 4-இல் உள்ள `create-admin` கட்டளையை மீண்டும் ஓட்டு (புதிய கடவுச்சொல் அமையும்).

## GST குறிப்பு
விலைகள் GST உள்ளடக்கியவை; ரசீதில் வரி பிரித்துக் காட்டப்படும் (CGST/SGST, உள்ளூர் விற்பனை). பொருளுக்கான GST விகிதத்தை (0/5/12/18%) ஒவ்வொரு பொருளிலும் அமைக்கலாம் — **சரியான விகிதத்தையும் டெலிவரி கட்டணத்துக்கான வரி முறையையும் உங்கள் கணக்காளரிடம் உறுதி செய்யவும்.** HSN குறியீடு ரசீதில் இல்லை (தேவைப்பட்டால் சேர்க்கலாம்).
